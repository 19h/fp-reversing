## Daemon reply and record parsing contracts

Under the source protocol and valid memory assumptions:

```text
if returned_size_t != 16 or returned_extent != submitted_extent:
    result = 0x74c29fc9
else:
    result = api_status xor 0x8b3dc651
    copy returned_extent bytes in descending address order
```

The caller's success marker is `0x8b3dc651`, equivalent to zero API status after shape guards. | Wire offset | Width | Interpretation |
| --- | ---: | --- |
| 0 | 4 bytes | Big-endian raw key, staged as `BE32 xor 0x8b3dc651` |
