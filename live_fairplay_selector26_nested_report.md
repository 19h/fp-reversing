# Selector 26 message construction and nested record dispatch

The installed FairPlayIOKit core consumes the 208 B or 224 B span copied from each of four reconstructed `fairplayd` aggregates. In sixteen offline replays, it constructs the message, publishes four linked records at `FPMessage+0x00`, queries five keys and reaches a private helper call with a workspace record pointer in X0. The first query misses and the following four return the corresponding node. Native daemon-to-kext pairing remains unknown.
