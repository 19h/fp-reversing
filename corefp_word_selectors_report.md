# CoreFP four-read word selectors and encoded-base/count lifetimes

Both word-pass splits are generated by four data-dependent word reads and five unsigned divisions. Under the selected control, each selector repeatedly adds a source constant to a decoded buffer word and takes the remainder modulo N. This recovers the complete local selector projections previously left as typed remainder inputs in the [word-traversal report](corefp_word_traversal_report.md). For nonzero 29-bit N, their final remainders satisfy `0 <= r1,r2 < N` independently of the word values.

The second selector decodes a separately biased pointer to the same buffer used by the first. It reads the first pass's XOR-encoded words and applies the common word decoder under the previously source-derived control `0x4d25`. Original-byte controls demonstrate different splits for different word contents. Native admission, backing/ownership, unrestricted table selection and hardware PAC acceptance remain unknown; no daemon/kext transport pairing is established.

## Compact selector functions [WS3-WS5]

Let W be the N-word buffer at the first selector, after the earlier byte prefix. W is not asserted to be the original application input. Let `u64(x)` truncate after each addition. Under WS5, both selectors use this fixed-size algorithm, with different constants:

```text
j = seed % N
for addend in four_addends:
    d = u64(W[j] + addend)
    j = d % N
return u32(j)
```

| Selector | Seed | Four addends, in source order | Primary source region |
| --- | --- | --- | --- |
| First | `68f4137b` | `4c536b54`, `c8b88f15`, `803e016b`, `a89af9c0` | `[0x1b45dc,0x1b46c0)` |
| Second | `1d486d12` | `2311ef95`, `700fa8fa`, `3ad4ce9e`, `e18eca0e` | `[0x1b54d0,0x1b55a4)` |

The initial division is u32. The four following divisions use u64 dividends; each dividend addition wraps modulo 2^64 before division. The final source MSUB writes a W register and truncates to u32. The certified remainder bound makes that truncation value-preserving for the nonzero 29-bit count domain.

| Selector | Word-load PCs, in order | UDIV PCs, in order | Final remainder |
| --- | --- | --- | --- |
| First | `1b461c`, `1b4634`, `1b468c`, `1b46a4` | `1b45fc`, `1b462c`, `1b4684`, `1b469c`, `1b46b4` | W10 at `0x1b46c0` |
| Second | `1b5510`, `1b5540`, `1b5564`, `1b5588` | `1b54ec`, `1b5530`, `1b5554`, `1b5578`, `1b559c` | W14 at `0x1b55a4` |

The second selector's physical loads return E, the first pass's encoded word. Loads two through four decode with literal K=`cccccccccccccccc`. Its first decoder instead uses:

```text
K0(C) = zero_extend_64(u32(C + 864e)) XOR cccccccccccc1fbf
```

At C=`4d25`, `K0(C)=K`. The source proofs retain the generic first-decoder expression and prove the selected equality separately. The complete generic second-selector formula replaces its first W lookup with `E[j] XOR K0(C)` and its other lookups with `E[j] XOR K`. Thus a different incoming control cannot silently inherit the common raw-word interpretation. The [word-input report](corefp_word_inputs_report.md) supplies original production of C from the selected master; the [codec report](corefp_word_codec_report.md) supplies E=`W XOR K`.

Each selector uses four reads and five divisions, so its arithmetic/lookup count and auxiliary storage are `O(1)`. This is an algorithmic operation count, not a claim about processor latency. The preceding full word traversal remains `O(N)`.

## Encoded pointer and count epochs [WS3,WS6]

The seven instructions `[0x1b2d68,0x1b2d84)` load the earlier biased record buffer field P from FP-`0xd0` = SP+`0x450`, add `41ee14e61969358b`, and store the result at SP+`0x70`. The second selector adds `a22256c23a653713` to that cached pointer. Their sum is the original buffer bias:

```text
encoded_base = u64(P + 41ee14e61969358b)
B            = u64(encoded_base + a22256c23a653713)
             = u64(P + e4106ba853ce6c9e)
```

This is the same record+`0x18` decoding used by the [entry-lineage report](corefp_input_lineage_report.md). The first selector obtains B from its separate u64 cache at SP+`0x468`.

| Lifetime | Producer | Consumer | Width / role |
| --- | --- | --- | --- |
| Raw biased pointer P | `0x1af858` | `0x1b2d78` | u64 at SP+`0x450` |
| Encoded selector base | `0x1b2d80` | `0x1b54f4` | u64 at SP+`0x70` |
| Word count N | `0x1b46b8` | `0x1b54e8` | u64 at SP+`0x450` |

All eighteen retained cache epochs have matching address, width and bytes with no intervening overlapping write. SP+`0x450` also has four-byte replacements before and after the count lifetime; these do not extend the earlier pointer or count roles. SP+`0x70` is later overwritten by a four-byte digest field at `0x1b6948`. Native structure-field names must not be assigned from these reused stack offsets.

The first selector decodes N from u32(SP+`0x3ec`) and stores the encoded count at SP+`0x458`. The proof represents the byte count as `(N<<3) OR residual3`, with arbitrary low three bits. It proves the six-instruction count binding before substituting X1=`zero_extend_64(N)` at `0x1b45f4`; this explicit normalization cut changes no replay bytes or component inputs. It then proves all four load addresses, the exact final remainder expression, survival of X1=N and the u64 cache store. The second selector reloads u64 N into X15 and preserves it through its final division.

## Division certificates, range and exceptional domains [WS3,WS4]

Arm's [A64 UDIV specification, DDI 0602, 2024-12](https://support.arm.com/documentation/ddi0602/2024-12/Base-Instructions/UDIV--Unsigned-divide-?lang=en) defines unsigned division at the selected 32/64-bit width, a zero result for a zero divisor and unchanged condition flags. The source lift encodes that zero case explicitly. Z3's default bit-vector UDiv zero case differs and is not substituted directly as the architectural operation.

The source queries prove exact modular expressions `D - UDIV(D,N)*N` and every load address using the source widths. Separate integer certificates prove, for `0 <= D < 2^64` and `1 <= N <= 0x1fffffff`:

```text
Q = floor(D/N)
R = D - Q*N
0 <= Q < 2^64
0 <= R < N
R mod 2^32 = R
0 <= 8*R <= 8*(N-1) < 2^32
```

These certificates also cover the smaller initial u32 dividend. For nonzero N, Q is exactly the architectural unsigned quotient. Its mathematical product Q*N is at most D, and the subtraction yields R, so the modular source MSUB agrees with the Euclidean remainder. The final u32 projection preserves R. The source and integer certificates are composed through this explicit width/architecture argument; the integer certificate does not itself emulate instructions or establish backing.

All four load indexes are therefore less than N. Under WS4, each read occupies eight bytes within the declared N-word array. The maximum relative start offset is `8*(N-1)` B; the read's exclusive end is at most `8*N` B. A relative offset bound does not prove that B names an allocation or that address addition cannot wrap.

N=1 produces remainder zero at every step and four reads of word zero. This is a valid local selector contract, but the nonempty head/tail traversal theorem still requires N>=2. For N=0, the original first u32 UDIV returns zero and its MSUB leaves the initial seed `68f4137b` as the first index. Six original-byte prefix controls stop immediately before the first buffer load at `0x1b461c`. They establish the scalar index, not native admission, an attempted invalid read or a fault. The earlier caller length gate and its native admission remain separate evidence.

## Retained chains and falsification controls [WS2,WS4-WS6]

Each of six whole callers has four first-selector reads before its corresponding raw word consumers and four second-selector reads after the corresponding encoder stores. Forty-eight same-word epochs check address, width, event order, identical bytes and absence of an intervening overlapping write. These joins bind the selector words to the earlier raw/encoded word contracts, rather than merely comparing final r values.

```text
record biased pointer P
    |-- original decode ------------------> first selector base B
    |
    +-- add 41ee14e61969358b --> u64(SP+70)
                                      |
                              add a22256c23a653713
                                      |
                              second selector base B

first selector: raw W reads --> r1 --> first bound encoder
                      |
               ordered word pass: E = W XOR K
                      |
second selector: E XOR K reads --> r2 --> second bound encoder

first source N --> u64(SP+450) --> second source N
```

All twelve selector-end frames equal their respective bound-encoder entry frames exactly. The prior traversal joins then reproduce head lengths `max(1,r)` and the selected dispatch rows. This discharges their previously external remainder range/value-generation premise under WS1-WS6. It does not discharge independent native backing, mutation, dispatch/PAC or admission premises.

The independent original-byte constant-word controls use a privately backed N=4 array, selected C=`4d25`, and the common first-pass encoding for the second selector:

| Every raw word W | First r1 / head length | Second r2 / head length |
| --- | --- | --- |
| 0 | 0 / 1 | 2 / 2 |
| 1 | 1 / 1 | 3 / 3 |
| 2 | 2 / 2 | 0 / 1 |
| 3 | 3 / 3 | 1 / 1 |

The table falsifies extrapolation of a constant first-head or second-tail length from the earlier six caller fixtures. It does not assert that these private buffers are natively admitted. Generic-control cases compare the full K0(C) formula and do not assume the selected common key.

## Validation, complexity and continuation

The regions contain 7 pointer-cache, 57 first-selector and 53 second-selector instructions: 117 instructions/468 B total. Eighteen executions contribute 702 visits, 78 reads/600 B and 48 writes/240 B with no regional PAC model. These regions overlap earlier source views and must not be added as disjoint global coverage.

The independent auditor imports no new producer. It reconstructs six initial CPU frames and 3313664 B of RAM and checks 488136 source visits, 63394 reads, 40562 writes, 21086 PAC models, 30 API/sequential-CASAL models, 182 state points and 3313664 B of final RAM, together with the existing workspace/preparation oracles. A separate integer interpreter compares all eighteen complete primary CPU/NZCV/stack frames and read/write journals, including UDIV, MSUB, UXTW, width truncation and stores.

Private original-byte finite tests use 2048 biased-pointer byte cases per caller; 2048 word-seed cases per selector with varying small counts; all counts 1 through 32, with eight low-three-bit residual cases per first-selector count; and 1024 generic u32 control cases per second selector. Per caller this is 2048 pointer-cache, 2304 first-selector and 3104 second-selector cases. Across six callers: 44736 cases/1861056 visits. Each scalar byte domain XORs a shifted byte with a diagnostic word; word arrays use deterministic per-index increments. These are finite samples, not exhaustive enumeration of buffers or count space.

Forty-eight constant-word split controls add 2640 visits. Six stopped zero-count prefixes and 12306 isolated original u64 UDIV cases add 12312 cases/12402 visits. The isolated division domains include all eight byte lanes plus dividend 0, 1 and `2^64-1`; they execute only the original instruction at `0x1b462c`, with a zero divisor and no memory read. All components preserve source bytes; primary finite cases compare the full stack against exact expected changes.

All 28 new and 1301 frozen obligations are independently UNSAT, totaling 1329 with a 30 s/query limit. The new set contains source bit-vector obligations and separate integer range certificates; their roles are explicit. The inherited set includes ten previously documented vacuous word-body entry bindings, so the aggregate count is not a count of independent nonvacuous discoveries.

Replay complexity is conservatively `O(C*(Bsrc+V*J+P*Fpage+R))` time/space for C profiles, source bytes Bsrc, visits V, journal/state cost J, touched pages P, frame/page payload Fpage and other retained bytes R. Finite component time is `O(K*L)` for K cases and source length L, with bounded private maps. Solver complexity is separate.

No native target/API/IPC or IDA operation occurs; original file evidence suffices. No new incoming/outgoing Mach port, right, descriptor, message emission or daemon/kext pairing is established. The full transform algorithm and general raw preparation contract remain unknown.
